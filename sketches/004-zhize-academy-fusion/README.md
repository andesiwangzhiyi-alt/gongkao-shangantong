## Variant: 致泽学堂 · 墨蓝融合版

### Design stance
以“现代书院”为品牌主体，结合效率工作台和温和成长反馈，形成可直接讨论的新版产品基线。

### Key choices
- 品牌：正式使用“致泽学堂”，主 Slogan 为“以学致知，以行泽民”。
- 图标：自绘“檐口 + 对开书页 + 三道水纹”的泽印书页 SVG。
- 布局：桌面墨蓝侧栏 + 主工作台 + 首页右侧任务栏；移动端五项底部导航。
- 首页：致学力、较上周变化、“你已超过上周的自己”、今日三项闯关。
- 行测：吸收清透效率台的模块工作台和二级入口。
- 成长：吸收暖阳成长的进步反馈，但不做金币、等级等重游戏化。
- 申论：保留一级页、素材簿/文章练习/批改记录二级骨架，具体内容移除。
- 问泽：AI 子品牌更名为“问泽”；首页直接提供文字/语音对话框，题目原始解析下方提供逐题对话框。
- 古风环境：加入远山、烟水、竹影、云水、疏梅、柳桥、月隐、清荷、素宣和无背景十种选择，以及可关闭的点击水纹涟漪。
- 导航：桌面顺序为学堂首页、行测研习、申论书房、修业成长、问泽、我的书斋。
- 响应式：桌面、平板、390px、320px 共用同一套 HTML。

### Interactions
- 桌面侧栏、移动底栏可切换全部一级页面；
- 首页能力卡、今日闯关和快捷入口提供状态反馈；
- 申论和 AI 的二级页面可进入、返回；
- 行测和成长部分二级页面可预览页面骨架；
- 行测页可进入“题目解析与问泽”示例，验证原始解析与 AI 辅助分区；
- 我的书斋可即时切换十种背景并关闭涟漪；
- 麦克风按钮可演示录音状态，明确不上传、不伪造转写；
- 所有占位功能明确标注，不伪造内容和服务能力。

### Trade-offs
- Strong at: 品牌辨识度、首页行动清晰度、桌面效率、移动端成长反馈、未来接口扩展。
- Weak at: 当前仍是设计原型，能力数字为视觉示意；题目页、完整筛选器和复杂图表尚未展开。

### Best for
- 作为致泽学堂正式改版前的融合方向候选稿；待用户确认品牌、导航、色彩和首页结构后，再进入生产实现。
