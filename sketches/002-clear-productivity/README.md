## Variant: 清透效率台

### Design stance
把上岸通定义为“备考生产力工具”，优先让用户看清任务、弱项和下一步。

### Key choices
- Layout: 顶部产品导航 + 双栏工作台，主区是训练与能力矩阵，右栏是今日清单。
- Typography: 全系统无衬线字体，数字突出，信息层级紧凑。
- Color: 深海军蓝 + 薄荷青，背景近白，状态色克制。
- Interaction: 今日建议一键开始；清单可勾选；模块、组卷、回填均有即时反馈。

### Trade-offs
- Strong at: 信息密度、效率、桌面端操作、专业工具感，易承接后续行测万卷筛选能力。
- Weak at: 情绪温度较低；手机端需把部分高级筛选放入二级页面。

### Best for
- 高频刷题、重视数据和自定义组卷的进阶考生；适合作为生产版本主方向。
