## Variant: 墨蓝书院

### Design stance
以“可信、沉静、长期主义”为核心，把备考产品做成一张现代书院式学习桌。

### Key choices
- Layout: 桌面左侧常驻导航，移动端改为横向入口；内容区留白充足。
- Typography: 标题采用宋体/衬线气质，正文保持系统字体可读性。
- Color: 墨蓝、米纸白、低饱和金，弱化传统教育 App 的高亮蓝。
- Interaction: 今日训练为唯一强主按钮，模块卡可进入答题浮层。

### Trade-offs
- Strong at: 品牌辨识度、信任感、长时间阅读、真题/申论内容承载。
- Weak at: 信息密度偏低，不适合在一屏展示大量筛选器。

### Best for
- 希望产品更像长期陪伴式学习工具、重视品牌气质与内容沉浸的用户。
