## Variant: 暖阳成长

### Design stance
弱化考试焦虑，用“每日闯关 + 能力生长”建立温暖、轻量、可持续的学习反馈。

### Key choices
- Layout: 单列成长首页，今日路线最突出；移动端底部五项导航。
- Typography: 圆润无衬线，标题亲切但不幼稚。
- Color: 暖橙、奶油白、深棕，避免冷冰冰的题库工具感。
- Interaction: 今日路线可进入底部答题 Sheet，任务与成长值形成连续反馈。

### Trade-offs
- Strong at: 新用户引导、降低压力、习惯养成、移动端亲和力。
- Weak at: 高级组卷和全库筛选需要进入二级“专业模式”；不宜把游戏化做得过重。

### Best for
- 备考初中期、容易被复杂数据压迫、需要稳定节奏与正向反馈的用户。
